## Problem

用户需要一款类似“wolai”（我来）的模块化块级（Block-based）桌面文档编辑器，兼具现代化积木式笔记排版体验与纯本地数据隐私掌控，第一版不需要任何云同步，文件完全存储在本地，并且存储格式与通用 Markdown 兼容，避免专有格式数据锁定。

## Target User

- 喜欢类 wolai / Notion 块级积木排版、快捷斜杠输入，但追求纯本地离线使用、重视数据隐私与掌控权的个人知识工作者与开发者。

## Core Scenario

1. **打开工作区**：用户启动应用，选择或切换本地的一个文件夹作为文档库工作区。
2. **页面管理**：在左侧树状视图中浏览、新建、重命名、删除 Markdown 页面及子文件夹。
3. **块级编辑**：在右侧主编辑区，以独立的 Block（段落、标题、无序/有序列表、待办任务、代码块、引用、分割线）组织内容；支持输入 `/` 弹出快捷命令菜单快速切换或插入块；键盘快捷键支持回车新建块、退格合并块、快捷格式（加粗/斜体/代码等）。
4. **实时落盘**：编辑内容自动落盘保存为标准 `.md` 文件，下次打开或重启应用时无损加载。

## In Scope (第一版确认范围)

1. **桌面端独立应用体验**：
   - 跨平台桌面客户端窗口，适配 macOS。
   - 原生系统菜单、本地文件对话框（选择工作区目录）。
2. **本地文件工作区与页面树**：
   - 支持指定本地目录作为工作区，自动扫描内部 `.md` 文件并构建树形目录。
   - 支持在左侧树新建文档、新建文件夹、重命名、删除文档。
   - 点击文件在主编辑区打开对应页面。
3. **核心块级（Block-based）文档编辑器**：
   - 块级结构：页面内容由自上而下的块序列构成。
   - 基础块类型支持：
     - 段落块 (Paragraph / Text)
     - 标题块 (H1, H2, H3)
     - 无序列表 (Bullet List)
     - 有序列表 (Numbered List)
     - 待办清单 (Todo Checklist，带复选框切换完成状态)
     - 引用块 (Blockquote)
     - 代码块 (Code Block，支持多行与等宽排版)
     - 分割线 (Horizontal Rule / Divider)
   - 块级核心交互：
     - 输入 `/` 弹出浮动命令菜单（Slash Command Menu），支持键盘上下键选择并回车转换或插入块。
     - `Enter` 智能换行（普通文本创建新块，列表项创建新列表项，连续两次回车跳出列表）。
     - `Backspace` 在空块按退格删除该块并聚焦上一块。
     - 选中文字支持快捷键加粗 (`Cmd+B`)、斜体 (`Cmd+I`)、行内代码 (`Cmd+E`)。
4. **本地 Markdown 双向持久化**：
   - 保存格式：标准 `.md` 文件，保证文件能用 VS Code、Obsidian 等通用工具直接打开阅读。
   - 自动保存：编辑停顿防抖自动保存至磁盘，防止数据丢失。

## Out of Scope (第一版明确排除)

- 云端多端同步与远程备份。
- 用户账号、登录与团队权限。
- 多人实时协同编辑。
- 复杂的数据库/多维表格视图（Database / Table View）。
- 双向链接图谱与高级反向引用（留待 v0.2 规划）。
- 云端分享链接与导出在线网页。

## Constraints

- 存储必须 100% 运行在本地磁盘，无外部网络依赖。
- 本地文件读写必须防抖并具备原子写入保护，避免意外断电或崩溃损坏文件。
- 编辑输入手感流畅，无卡顿感。
