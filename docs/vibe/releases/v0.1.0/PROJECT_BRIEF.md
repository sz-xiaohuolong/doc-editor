## Problem

用户需要一款类似“wolai”（我来）的模块化块级（Block-based）桌面文档编辑器，兼具现代化积木式笔记排版体验与纯本地数据隐私掌控，第一版不需要任何云同步，文件完全存储在本地，并且存储格式与通用 Markdown 兼容，避免专有格式数据锁定。

## Target User

- 喜欢类 wolai / Notion 块级积木排版、快捷斜杠输入，但追求纯本地离线使用、重视数据隐私与掌控权的个人知识工作者与开发者。

## Core Scenario

1. **首期开箱**：用户首次打开 macOS 客户端，系统引导用户选取或新建本地工作区目录（默认推荐 `~/Documents/DocEditorWorkspace`），并自动载入内置的《👋 欢迎与快速上手 (Welcome.md)》示例页面。
2. **页面管理（Folder-Notes）**：左侧树状视图中，每个页面既能承载正文，也能挂载子页面；支持新建、重命名、删除。
3. **页面标题联动**：页面顶部提供大标题输入框，修改标题自动联动重命名底层对应的 `.md` 文件与关联子目录。
4. **块级积木编辑**：在右侧主编辑区，以独立的 Block 组织内容；鼠标悬浮显示六点拖拽手柄（⠿），支持鼠标拖拽改变块顺序；按 `Esc` 进入块选中态；输入 `/` 弹出快捷命令菜单快速切换或插入块；键盘快捷键支持回车智能分块、退格合并块、行内样式格式化。
5. **富内容与多媒体**：支持 Callout 提示框（高亮底色与 Emoji，兼容 GFM 语法）；支持从剪贴板粘贴本地图片（自动拷贝存入工作区 `assets/` 目录并插入相对路径引用）。
6. **纯净 Markdown 落盘与热监听**：编辑内容防抖（1秒）自动落盘保存为 100% 纯净的标准 `.md` 文件；后台监听工作区文件变动，外部增删文件自动刷新侧边栏，外部修改当前正在编辑的文件时弹出防冲突确认框。

## In Scope (第一版确认范围)

1. **桌面端独立应用 (Tauri 2.0)**：
   - macOS 原生独立窗口，秒级冷启动，轻量资源占用。
   - 原生系统菜单、文件对话框（选取工作区）。
2. **工作区与 Folder-Notes 页面树**：
   - 选取本地目录作为工作区，自动递归扫描 `.md` 文件建立层级树。
   - 页面即目录心智：页面 `Note.md` 与子页面目录 `Note/SubNote.md` 映射。
   - 页面新建、删除、重命名；顶部标题输入框与底层文件名双向联动。
3. **Tiptap/ProseMirror 核心块级（Block-based）文档编辑器**：
   - 块类型支持：
     - 段落块 (Paragraph / Text)
     - 标题块 (H1, H2, H3)
     - 无序列表 (Bullet List)
     - 有序列表 (Numbered List)
     - 待办清单 (Todo Checklist，带勾选框，对应 `- [ ]` / `- [x]`)
     - 引用块 (Blockquote)
     - 代码块 (Code Block，等宽字体与语法高亮)
     - 分割线 (Horizontal Rule / Divider)
     - Callout 提示框 (GFM `> [!NOTE]` 规范语法，带图标高亮底色)
     - 本地图片块 (支持剪贴板粘贴截图，自动存入 `assets/` 相对路径)
   - 块级交互体验：
     - 块左侧悬浮六点手柄 (⠿)，支持拖拽上下调换块顺序。
     - 按 `Esc` 键激活块选中模式，支持上下箭头切换选中块，回车再次进入编辑。
     - 输入 `/` 弹出浮动命令菜单（Slash Command Menu），支持键盘过滤与回车转换/插入。
     - `Enter` 智能换行（文本创建新块，列表项创建新列表项，连续两回车退出列表）。
     - `Backspace` 空块回退删除并聚焦上一块。
     - 基础行内样式快捷键：粗体 (`Cmd+B`)、斜体 (`Cmd+I`)、行内代码 (`Cmd+E`)、删除线。
4. **100% 纯净 Markdown 双向持久化与文件监听**：
   - 磁盘文件只保留标准 Markdown 语法，不注入私有垃圾注释，与 Obsidian/VS Code 完美互通。
   - 编辑防抖自动保存（1秒）。
   - 文件系统热监听：外部增删自动刷新左侧树，外部修改当前打开文件弹出防覆盖提示。
5. **首期引导体验**：
   - 引导选取工作区，并自动生成《欢迎与快速上手 (Welcome.md)》包含所有块类型示例。

## Out of Scope (第一版明确排除)

- ❌ 云端账号与鉴权登录系统
- ❌ 云端多端自动同步与备份服务
- ❌ 多人实时协同编辑
- ❌ 多维表格 / Database 数据库视图（表格筛选/看板/日历等）
- ❌ 双向链接反向引用图谱（规划至 v0.2）
- ❌ 公开分享链接与导出在线 Web 页面

## Constraints

- 存储必须 100% 运行在本地磁盘，无外部网络依赖。
- 架构采用 Tauri 2.0 (Rust 负责原生文件系统与文件监听) + React 18/TypeScript + Tailwind CSS + Tiptap/ProseMirror。
- 必须保证与通用 Markdown 文件的双向往返（Round-trip）无损转换。
