## Product Behaviors

### REQ-007 — 双向链接输入与渲染 (WikiLink)

- Source: `PROJECT_BRIEF.md` REQ-007
- Actors: 终端用户
- Preconditions: 工作区已加载，正在编辑器中打字
- Trigger: 用户在编辑器中键入 `[[`
- Expected Behavior:
  1. **输入触发**：在任意行内文本中输入 `[[` 时，立即在当前光标下方唤起浮动页面选择菜单。
  2. **模糊与拼音过滤**：随着用户继续输入文字（如 `[[欢迎` 或 `[[hy`），动态过滤工作区中的页面标题，高亮显示最佳匹配项。
  3. **选择与插入**：
     - 用户按下 <kbd>Enter</kbd> 或鼠标点击目标页面项时，替换掉触发文本 `[[...`，生成一个行内 `WikiLink` 药丸节点。
     - 药丸节点呈现 wolai 风格的高级排版视觉：柔和蓝紫/灰色半透明底色、优雅的圆角药丸框（`rounded-md px-1.5 py-0.5`），左侧带有页面链接微图标（📄 或 🔗），右侧显示目标页面标题。
  4. **点击平滑跳转**：
     - 在阅读或编辑态下单机药丸标签，直接平滑导航切换到目标页面，侧边栏树节点同步高亮。
  5. **纯净标准 Markdown 序列化**：
     - 底层 `.md` 序列化时采用标准的 `[[目标页面名称]]` 语法；
     - 重新加载时，自动解析 `[[目标页面名称]]` 为 WikiLink 行内节点，保持与 Obsidian、Logseq 等生态无缝互通。
- Resulting State: 编辑器中生成了交互式双链节点，底层 Markdown 保存为 `[[目标页面]]`。
- Explicit Non-goals: 不支持跨网络远程双链，暂不支持跨仓库 URI 双链。

#### Acceptance Criteria
- AC-023: 在编辑器任意文本位置输入 `[[`，立即在光标下方弹出当前工作区页面联想菜单。
- AC-024: 支持拼音或中文关键词模糊过滤页面，按回车或鼠标点击完成插入，生成具有 wolai 质感的内联双链药丸标签。
- AC-025: 单击双链标签能平滑导航并切换到目标页面。
- AC-026: Markdown 序列化时采用标准的 `[[页面标题]]` 语法，与其他外部笔记软件完全互通。

#### Error Scenarios
- ERR-007: 若引用的目标页面在磁盘被重命名或删除，双链标签显示为微灰斜体（无死链崩溃），点击提示“目标页面不存在”。

### REQ-008 — 反向链接面板 (Backlinks Panel)

- Source: `PROJECT_BRIEF.md` REQ-008
- Actors: 终端用户、文档引擎
- Preconditions: 打开任意文档
- Trigger: 文档加载完成或工作区文档变更
- Expected Behavior:
  1. **页面底部折叠面板**：
     - 在主编辑区最底部挂载“反向链接 (Backlinks)”卡片区，展示“反向链接 (N)”计数徽标。
     - 默认若引用数 > 0 则自动展开或支持用户一键折叠/展开。
  2. **引用关系扫描与上下文提取**：
     - 本地检索整个工作区所有的 `.md` 文件，找出包含 `[[当前页面名称]]` 的来源文档。
     - 提取每个来源文档中包含该链接的具体行/块文本作为上下文摘要（前后关联语句切片）。
  3. **卡片展示与快速回溯**：
     - 展示来源文档标题与上下文切片高亮；
     - 点击任意反向链接卡片，平滑跳转打开对应的来源文档。
- Resulting State: 用户可在任意文档底部清晰看到“是谁在引用我”，形成完整的双向网状知识连接。
- Explicit Non-goals: 不支持昂贵的实时图形力导向可视化（留待未来全景图谱版本）。

#### Acceptance Criteria
- AC-027: 页面底部常驻反向链接（Backlinks）统计折叠面板，展示所有引用了当前文档的来源文档数量与列表。
- AC-028: 展开后展示来源文档名称以及引用所在块的上下文文本切片。
- AC-029: 单击反向链接卡片可直接跳转至来源文档。

### REQ-009 — 全局搜索快捷唤起与 CJK 分词检索 (Global Search)

- Source: `PROJECT_BRIEF.md` REQ-009
- Actors: 终端用户
- Preconditions: 任意主界面状态
- Trigger: 按下快捷键 `Cmd+P` / `Ctrl+P` 或点击侧边栏“搜索”按钮
- Expected Behavior:
  1. **快捷唤起与居中浮层**：
     - 按下 `Cmd+P`（Mac）或 `Ctrl+P`（Windows）或者在侧边栏点击“搜索”，主界面立即弹出全局居中的搜索模态框，输入框自动获得焦点。
  2. **本地 CJK Unigram 搜索引擎**：
     - 索引覆盖当前工作区所有页面的大标题与正文段落。
     - 采用单字与双字滑动窗口（Unigram + Bigram）及英文单词 Token 混合切分，无需联网，在本地毫秒级生成倒排匹配。
  3. **实时匹配与高亮渲染**：
     - 输入关键词时，实时计算各文档得分并展示前 N 项结果。
     - 列表中清晰展示：文档标题、匹配命中的正文段落切片，命中关键词带有柔和黄色或粉色加粗高亮。
  4. **全键盘流体验**：
     - 按 <kbd>↓</kbd> / <kbd>↑</kbd> 在搜索结果中上下高亮移动；
     - 按 <kbd>Enter</kbd> 立即打开并跳转至对应文档，模态框自动关闭；
     - 按 <kbd>Esc</kbd> 退出搜索并返回原工作状态。
- Resulting State: 用户可在数毫秒内定位整个笔记库的任意知识内容。

#### Acceptance Criteria
- AC-030: 支持按下全局快捷键 `Cmd+P`（Mac）/ `Ctrl+P`（Windows）或点击侧边栏“搜索”按钮唤起全局搜索弹窗。
- AC-031: 纯本地搜索索引覆盖工作区所有页面的大标题与正文块，内嵌 CJK 单字/双字 Unigram 分词算法。
- AC-032: 搜索输入时实时更新结果列表，并对匹配关键词进行加粗/高亮渲染。
- AC-033: 支持方向键 ↑ / ↓ 切换选中项、Enter 确认跳转打开页面、Esc 退出弹窗。

#### Error Scenarios
- ERR-008: 当搜索无匹配结果时，展示“未找到与关键词相关的页面”的空状态友好提示，不造成卡顿或白屏。

### REQ-010 — 多格式本地文件导入流水线 (Local File Import Pipeline)

- Source: `PROJECT_BRIEF.md` REQ-010
- Actors: 终端用户、文件转换引擎
- Preconditions: 工作区已打开
- Trigger: 点击侧边栏底部的“导入文件”按钮
- Expected Behavior:
  1. **系统文件选取**：
     - 调起原生文件选择器，过滤器支持：`.md`, `.markdown`, `.txt`, `.html`, `.htm`, `.docx`。
     - 支持单选或多选批量导入。
  2. **纯本地安全转换流水线**：
     - **Markdown / TXT**：以 UTF-8 读取内容，文件主名作为新页面标题；若正文中含有本地图片相对路径，自动扫描并安全转存至工作区的 `.assets/` 目录并更新相对路径。
     - **HTML / HTM**：通过本地纯前端 DOM 规范解析树（或 Turndown 规则），将富文本标题、段落、列表、代码块、表格转换为纯净 Markdown 块。
     - **Word (.docx)**：使用本地前端 `mammoth` 库，离线将 docx 的段落、标题、列表提取转为干净的 HTML/Markdown 文本，文档中嵌入的图片提取为二进制并存入工作区 `.assets/` 目录。
  3. **创建新页面并刷新联动**：
     - 转换完成后，在当前工作区根目录下创建对应 `<标题>.md`；
     - 若同名文件已存在，自动追加递增序号（如 `<标题> (1).md`），严禁静默覆盖用户已有文档；
     - 导入完成后，侧边栏页面树自动刷新，应用自动切换并打开最新导入的文件。
- Resulting State: 外部多格式文档安全、无损、离线地转为工作区原生页面。
- Explicit Non-goals: 第一版不支持带复杂公式宏的加密 docx，不支持多层 Notion zip 深度嵌套递归解压（支持单文件解包导入）。

#### Acceptance Criteria
- AC-034: 侧边栏底部提供明显的“导入文件”入口，支持多选 `.md`, `.txt`, `.html`, `.docx`。
- AC-035: 导入流水线完全在本地执行，无需联网：
  - Markdown/TXT：直接按文件标题创建新页面，内嵌图片自动提取/重写存入 `.assets/`；
  - HTML/Word：本地解析为规范的 Markdown 块结构后新建页面。
- AC-036: 导入成功后左侧文档树即时响应刷新，并自动高亮切换到新导入的页面。

#### Error Scenarios
- ERR-009: 导入损坏的 `.docx` 文件时，提示“无法解析该 Word 文件”，不影响其他已选文件的导入。
- ERR-010: 导入重名文档时，自动更名为 `<文件名> (1).md`，避免覆盖现有数据。
- ERR-011: 导入大文件（>50MB）时，显示处理等待遮罩，防止 UI 假死。
