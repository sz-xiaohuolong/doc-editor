- Requirement Status: **FROZEN**

- Target Release ID: `v0.2.0`
- Baseline Audit: 2026-10-10

---

## 1. 目标与背景
基于前期对 wolai 的深度逆向工程（OT 操作集、FlexSearch CJK 分词索引、双向链接引用元组、文件导入 AST 流水线），在当前 `doc-editor` 本地块级编辑器中进行**净室复刻与工程超越**：
脱离云端依赖与碎片化私有 LevelDB 黑盒，坚持 **“100% 纯本地、纯 CommonMark 存储、绝对数据主权”** 的核心原则，落地以下三大关键核心能力：
1. **块级编辑器双向链接机制**：支持输入 `[[` 联想并插入页面双向链接（WikiLinks），页面底部自动聚合反向链接（Backlinks）上下文卡片。
2. **全局搜索功能**：支持 `Cmd+P` / `Ctrl+P` 随时快捷唤起全局搜索模态框，内置 CJK Unigram 本地极速全文检索，展示匹配上下文高亮与键盘流导航。
3. **本地文件导入流水线**：支持 Markdown/TXT/HTML/Word(.docx) 多格式纯本地导入，自动识别内嵌媒体并转存至本地 `.assets/`，自动重构相对路径。

## 2. 功能范围与验收目标 (Acceptance Goals)

### REQ-007: 双向链接输入与渲染 (WikiLink)
- **AC-023**: 在编辑器任意文本位置输入 `[[`，立即在光标下方弹出当前工作区页面联想菜单；
- **AC-024**: 支持拼音或中文关键词模糊过滤页面，按回车或鼠标点击完成插入，生成具有 wolai 质感的内联双链药丸标签；
- **AC-025**: 单击双链标签能平滑导航并切换到目标页面；
- **AC-026**: Markdown 序列化时采用标准的 `[[页面标题]]` 语法，与其他外部笔记软件（如 Obsidian）完全互通。

### REQ-008: 反向链接面板 (Backlinks Panel)
- **AC-027**: 页面底部常驻反向链接（Backlinks）统计折叠面板，展示所有引用了当前文档的来源文档数量与列表；
- **AC-028**: 展开后展示来源文档名称以及引用所在块的上下文文本切片；
- **AC-029**: 单击反向链接卡片可直接跳转至来源文档。

### REQ-009: 全局搜索快捷唤起与 CJK 分词检索 (Global Search)
- **AC-030**: 支持按下全局快捷键 `Cmd+P`（Mac）/ `Ctrl+P`（Windows）或点击侧边栏“搜索”按钮唤起全局搜索弹窗；
- **AC-031**: 纯本地搜索索引覆盖工作区所有页面的大标题与正文块，内嵌 CJK 单字/双字 Unigram 分词算法；
- **AC-032**: 搜索输入时实时更新结果列表，并对匹配关键词进行加粗/高亮渲染；
- **AC-033**: 支持方向键 <kbd>↑</kbd> / <kbd>↓</kbd> 切换选中项、<kbd>Enter</kbd> 确认跳转打开页面、<kbd>Esc</kbd> 退出弹窗。

### REQ-010: 多格式本地文件导入流水线 (Local File Import Pipeline)
- **AC-034**: 侧边栏底部提供明显的“导入文件”入口，支持多选 `.md`, `.txt`, `.html`, `.docx`；
- **AC-035**: 导入流水线完全在本地执行，无需联网：
  - Markdown/TXT：直接按文件标题创建新页面，内嵌图片自动提取/重写存入 `.assets/`；
  - HTML/Word：本地解析为规范的 Markdown 块结构后新建页面；
- **AC-036**: 导入成功后左侧文档树即时响应刷新，并自动高亮切换到新导入的页面。

## 3. 非功能与质量边界
- **无云端黑盒**：严禁向任何外部网络上传用户文件与内容；
- **纯净 Markdown**：不向 `.md` 源码中注入非标准私有 HTML 属性或二进制垃圾；
- **零破坏性**：所有现有 v0.1.0 功能（六点手柄、多级标题、待办清单、Callout、图片粘贴、热监听）必须 100% 保持稳定。
